# Antigravity 智能体执行准则与约束规范 (Mandatory Execution Policy)

本文件确立 Antigravity 智能体在当前项目工作空间中执行任何任务时必须终身遵守的最高准则：

## 一、 核心红线与约束 (Non-Negotiable Invariants)

1. **严禁修改原代码与任何业务逻辑 (No Modification of Original Code)**
   - Antigravity 在执行任何抓取、规划、测试或运维任务时，**绝对不能修改现有代码和其任何业务逻辑**。
   - 严禁擅自修改已存在的源码文件（包括 `.py`, `.cpp`, `.hpp`, `.launch`, `.yaml` 等）。
   - 只执行任务，并对系统现象与硬件反应进行客观、严谨的记录与分析。

2. **允许添加专用的监控与分析代码 (Allowed Extensions)**
   - 允许新增独立的数据监控脚本、看门狗程序、时序数据记录器或行为分析工具（如 `tools/live_stream_supervisor.py` 等）。
   - 新增工具不得侵入或破坏原代码的运行机制与接口契约。
   - 可以根据现象向用户提出建设性的优化意见与分析建议，由用户决定是否修改。

3. **数据流完整记录 (Full Telemetry Recording)**
   - 执行过程中，必须全力、详实地记录各终端与 ROS 主题的数据流变化（包括关节位姿、电机状态、视觉检测、6D 门控审计、规划时延与日志输出）。
   - 记录的数据流需为后续与用户拍摄的实机抓取运动轨迹视频、控制代码进行多维度联合分析提供完整佐证。

4. **电机使能保护 (Torque Preservation)**
   - 严禁未经用户明确指示擅自发布任何关闭扭矩、下电或停止关节使能的命令。
