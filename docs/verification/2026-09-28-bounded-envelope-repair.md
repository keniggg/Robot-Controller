# 2026-09-28 实验往返包络和初始同步边界修复

本次仅修改 `.runtime` 实验脚本，没有启动 ROS、调用硬件或加载生产节点。

J3 往返原来每次以当前实测姿态重新生成 ±4.8° 包络。若去程已移动约 2°，返程几何证明就会覆盖一个额外偏移的区间，导致原始允许范围仍可返回、但扩大后的相机视野包络被拒绝。现在在新进程的 fresh measured baseline 冻结 J3 绝对上下限；去程及返程都根据各自的新几何重新证明原始完整区间及 SDK 目标。目标和实际反馈均不得越过原限值，每一条 accepted 回调都会锁存越界，即使下一帧回到范围内也不会清除故障。既有 40 mm 平面、20 px 视野、350 ms 图像、300 ms 反馈、同 epoch、方向/非编辑轴、SDK 字和双命令约束保持。

基础 J2/J5 脚本增加 `--bootstrap-sync-bound-deg 2`。它必须与显式 `--execute --bootstrap-pending --joint 5 --step-deg 2` 一起使用，取值仅允许 2 或 4.8，省略时默认仍为 4.8。该值同时传入六轴单轴几何 reservation 和实际同步总 L1 位移守卫；每条同步反馈均检查总 L1，超过后不再发送后续命令。这只缩小显式初始同步的响应界限，不更改后续 J5 动作的既有界限，没有自动降级或重试路径。

离线验证：首次组合 124 项通过；新增真实归档 URDF（合成固定标定板、模拟 MoveIt 服务）端点用例后，bootstrap 全组 20 项通过；合计 126 个不同用例通过。包括返程绝对最大/最小值不扩张、原区间外但位于旧重心包络内的位置拒绝、瞬时越界锁存、多轴同步总 L1、参数授权范围、几何端点、原有图像精确配对和新鲜度回归。测试设置 OPENBLAS_NUM_THREADS=1 和 OMP_NUM_THREADS=1。离线几何用例不能代替下一次运行的真实 fresh 场景证明。

旧 driver epoch 的 return 不能复用；脚本仍只接受新进程的当前状态与当前参考，没有加载旧计划入口。同步几何仍采用既有的各单轴端点采样，不宣称已经证明连续六维 L1 球中的全部混合配置。
