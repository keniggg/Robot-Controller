# 扩域运动学候选的独立只读复审

结论：冻结的 45 样本候选具备进入新一轮有界实机验证的数值依据；本结论不授权部署，也不代表已解决实体抓取高度误差。

审查对象位于 `ros_log/grasp_repair_resume_20260928T120606Z/expanded_metric_training_once/`。45 个训练源为原 22 个与原 task 的 16/2/5 三组，8 个原独立样本、08:42 空抓、后续 J1 和 J2/J3 居中均未进入该拟合目标。输入摘要、同一 URDF/SDK 相机模型/基线手眼、10 参数、原边界、0.1°与1 mm权重、零初值单次拟合均核对通过。没有重拟合或修改运行参数。

原 16/2/5 task 组现在是训练数据，不能再用于声称独立通过。扩域是在旧 22 候选的空抓验证失败后决定的；因此这些旧闭袋结果是模型开发中重复使用的验证证据，不是新的盲测。下一轮新采样须保持候选冻结。

独立复算没有使用原指标汇总函数：另写 URDF FK，使用矩阵 SVD 求原 22 训练位姿的固定参考，再计算独立 8 样本。位置 RMS/max 为 **0.591864/0.822819 mm**，姿态 RMS/max 为 **0.140173/0.257268°**，通过原 **3/5 mm、1/2°**标准。45 训练每组最大两两原点差均小于 3 mm；训练误差不作为独立证据。

空抓共视桌面 18 个固定原始 patch 的中心高度差最大 0.911152 mm。进一步计入平面法向差后，原 XY 圆形 patch 的欧氏半径不超过 `r/abs(n0.z)`，刚体变换保持该半径；整个 patch 的两平面差保守界为：

`abs(anchor_signed_distance) + 2*sin(angle/2)*r/abs(n0.z)`。

所有 patch 最大界 **2.541297 mm**，法向变化最大 **1.046346°**，低于原 **4 mm/4°**。这个界只适用于已归档共视桌面，不延伸为不可见电机、指尖或碰撞许可。局部 J3 某项从约 1.69 到 1.83 mm 没有单调改善，但仍在原标准内；没有新增“每项必须改善”的要求。

URDF 表达应为 `origin_new = [R_old @ Exp(axis_local*delta), xyz_old]`；joint axis、raw encoder/command、限位不变。这使 `FK_new(q) == FK_old(q+delta)`。另写实现对全部 55 原始姿态及 200 随机姿态验证，最大矩阵差 **1.22e-15**。必须使用完整旋转矩阵再转换 URDF 的 extrinsic xyz RPY，不能直接逐分量加 RPY。候选手眼 X 必须与该 URDF 成对使用，其旋转修正采用工具坐标内的左乘旋转向量。

完整复审 JSON 与独立复算源码在：
`ros_log/restart_grasp_20260929T013841Z/expanded_metric_independent_review/`。

尚不能把拟合零位数值解释为物理编码器零位的独立测量；同一 D405、板印刷尺度、机械形变与模型误差仍可能被等效参数吸收。相同哈希保证数值来源一致，不独立证明机械装配未变化。以上限制不阻止有界新实机验证，但阻止将离线拟合直接称为已验证部署。
