# 2026-09-28 坐标链辨识：固定手眼平移假设与对向双关节实验

本轮独立离线分析没有修改 TF、URDF、相机参数，也没有发送 ROS 命令。现有 J2/J3/J5 小角度数据不支持直接使用一个稳定的固定手眼平移修正消除全部漂移；它们的转轴接近平行，第三个平移方向的辨识很弱。下一轮应使用 J2/J3 对向转动产生近似纯平移，并保留一个非平行腕轴姿态作为留出检验，不应继续仅用相同小角度单轴往返证明重复性。

## 数据、坐标与方法

数据仅来自新固定板三个已关闭实验：

- `bounded_joint_response_20260928T105805Z_23293`（J5）；
- `bounded_joint_response_20260928T105915Z_24761`（J2）；
- `bounded_joint3_response_20260928T110035Z_26293`（J3，仅出向）。

多帧输入为 `grasp_repair_resume_20260928T104059Z/j{5,2,3}_multiframe_*/samples.json`。沿用其 source-time 精确配对、350 ms 年龄、模型 fingerprint、独立反馈静止窗口筛选。每个窗口按 0.5 s 非重叠时间块计算平均，再对时间块等权平均，避免高帧率片段获得额外权重。这个结果与此前所有跨窗帧对的中位数统计对象不同，不能把数值差异当作新运动。

设 `A = base_T_tool`、`X = tool_T_camera`、`C = camera_T_board`。对每个实验，固定手眼旋转，仅允许工具系平移改变量 `δt`。同一块板在出向与基线之间的位置差满足：

`d + (mean(R_A,out) − mean(R_A,base)) δt = 0`。

三个实验分别做窗口差，因此没有将旧板或不同会话的绝对板坐标混入拟合。分别评价板原点与板几何中心 `[90, 67.5, 0] mm`，后者降低绕板原点的小角度噪声对远处点的杠杆影响；两点结果差异也揭示未由平移模型解释的旋转变化。采用 500 次窗口内时间块重采样，报告条件性重复性范围，而非外部精度置信区间。

源 URDF SHA256 为 `890592a24b8ad818d995e69beb670ea4254bf84f589615bfac3c8562f62449b7`。手眼仍为 `d405_cc200_auto_20260927_validated_eye_on_hand.yaml`，SHA256 `6ab0e8c902fe87bad1935a69b72044930b79ce1b239728cfce6dda8e94533468`。

## 固定平移能否解释各轴

设计矩阵的秩为 3，奇异值为 `[0.050898, 0.050883, 0.001220]`，条件数 **41.72**。最弱方向几乎沿工具系 Y。若只保留 J2/J3，秩为 2，沿共同转轴的平移完全不可辨识。当前姿态中，J2 与 J3 的 URDF 转轴平行，J5 与 J2 仅相差 **3.252°**；J4、J6 与 J2 则约相差 90.000°、88.498°。

| 评价点 | 拟合工具系 δt（mm） | J5 残差（mm） | J2 残差（mm） | J3 残差（mm） |
| --- | --- | --- | --- | --- |
| 板原点 | `[13.84, −56.75, −13.78]` | 0.399 | 0.306 | 0.368 |
| 板中心 | `[13.22, −83.34, −14.68]` | 0.471 | 0.330 | 0.400 |

未拟合时板中心 J5/J2/J3 的窗口平均位移分别为 0.0587 / 0.9097 / 0.7087 mm。该拟合虽然减少 J2/J3 的平均偏差，却明显破坏原先较稳定的 J5。板原点换成中心后，工具系 Y 修正变化 **26.6 mm**，说明这不是可直接部署的稳定标定结果。

板中心拟合的 2.5%–97.5% 时间块重采样分位范围：X 为 12.46–14.05 mm、Y 为 −101.30 至 −65.69 mm、Z 为 −16.33 至 −13.12 mm。这些范围未包括板印刷尺度、内参、受力变形或 FK 系统误差，不能作为参数精度承诺。

留一关节的预测残差为 J5 **0.624 mm**、J2 **0.596 mm**、J3 **0.509 mm**。留出 J5 后，训练矩阵本身只有秩 2；此时最小范数解只是众多可能解之一。返回窗口的残差很小，但 J2 返回的 `R_out − R_base = 0`，完全不能约束固定平移；J3 没有真实返回记录。因此返回重复性不是这项拟合的独立广姿态验证。

另以原空抓的公共可见桌面补片做真正跨姿态留出：仅按 `d′ = d − n·R_tool δt` 重表达每个已拟合平面，不重新拟合、不更改图像、不混入新板绝对位置。原闭爪前相对初始的 −9.94 至 −10.01 mm 漂移，被板原点拟合预测为 **+4.23 至 +4.83 mm**，板中心拟合则预测为 **+6.25 至 +7.10 mm**。两者都发生过补偿，仍残留数毫米，进一步说明局部拟合不是可用于旧抓取的广姿态修正。这个留出计算仍共享原相机/FK系统误差，不是独立物理尺量。

这批数据支持的结论是：**不能只改手眼平移就宣布问题解决。** 它尚不足以把误差唯一归因于手眼旋转、链节参数、真实关节响应或 RGB 几何模型，也不足以外推覆盖原抓取的大幅姿态变化和约 10–11 mm 偏差。

## 不用手眼参数估计螺旋轴

固定板条件下，相机的板系刚体运动为 `G = inverse(C_after) C_before`。由 G 的旋转轴和 `(I − R)c = t` 估计转轴的位置；这个计算完全没有使用 X。对于平行的 J2/J3，两个轴的间距在任意固定刚体坐标变换下不变，原则上可以独立于手眼检验 URDF 的轴间距。

本批小角度数据得到：

- 相机两轴方向相差 0.661°；这是估计值，不应强行称其物理不平行。
- 施加共同平行方向后的轴间距为 **219.87 mm**。
- 当前 URDF 的 J2/J3 轴间距为 **224.808 mm**。
- 时间块重采样的轴间距约为 **214.57–224.79 mm**；轴夹角约为 0.378–1.488°。

这里 1.7°–1.9° 的运动使平移噪声在轴位置解中放大约 30–34 倍。重采样上端距 URDF 仅约 0.015 mm，远小于未计入的系统误差；不能据此判断链节真的短了 5 mm。板印刷尺度与 RGB 内参误差同样改变这个相机度量，因此该方法能区分“固定手眼”与“手眼以外的相对几何不一致”，不能单独区分 URDF 长度和相机/板尺度。

## 下一轮有限调姿合同

纯函数实现为 `.runtime/coupled_joint23_geometry.py`。它没有 ROS 导入、设备句柄或写入参数的接口，只返回数值候选及评价，不能直接作为执行授权。

1. 从同一新 epoch 的当前 accepted q、实际写入的 SDK q、最新 X/Y 和当前 SDK 投影模型构造候选。相机来源不超过 350 ms，accepted/SDK 不超过 300 ms，相机与 accepted 来源相差不超过 100 ms。每段执行前仍须由调用方重新取景、核对控制权、保持独立静止证据并检查当前 MoveIt 场景。
2. 选择 2–4° 的 SDK 幅度，量化为 22–45 个刻度。固定执行顺序为 **正向对转 → 原 SDK → 反向对转 → 原 SDK**：正向增加 J2、等量减少 J3，反向相反，其他 SDK 刻度与夹爪指令保持原值。至少分析正、负两个端点和各次返回；不能只有一个方向就拟合补偿。
3. 以初始 measured q 为中心保留 J2/J3 各 ±4.8° 的原始绝对响应界限，返回时不得重新以终点为中心扩大。双关节可能不同步，每段必须检查独立二维区间，不能只检查理想对角线。纯离线候选器先给出整个 ±4.8° 方形的保守结果；如果实机执行器另有明确的方向/反向响应守卫，则每段可以检查“新鲜 measured 到 target 的各轴有向范围加守卫规定的反向余量”与原绝对界的交集。该优化必须与实际执行守卫一致，不能仅因为方形拒绝就缩小范围。候选目标本身越界必须拒绝，不能夹取到边界后冒充原指令。几何阈值沿用 40 mm CAD 平面净距、20 px 全板边距、0.12 m 相机前向距离。密集采样不等于连续碰撞证明，仍须当前 MoveIt 与执行监测。
4. 每个停稳窗口保存多帧原始 RGB、同源深度、quality、TF、raw/accepted/SDK、epoch 和来源时间；同时报告板中心位置与旋转散布。建议每窗至少 10 个精确配对帧、跨越 2 s 以上，并保留完整静止窗口。配对不足只表示观测不充分，不能放宽来源年龄或复用旧帧。
5. 比较 **实际反馈 FK** 的相对旋转以及相机相对旋转，不能把命令的正负抵消当作实际抵消。先标记 FK 旋转是否小于一个编码刻度（0.087891°），再显式报告旋转残差的杠杆影响。
6. 对固定手眼平移改变量上界 `||δt|| ≤ L`，残余旋转 θ 造成的位置变化上界为 `2 sin(θ/2) L`。例如 θ 为一个编码刻度时，每 10 mm 平移修正只能造成约 0.0153 mm 的差分；假设修正范数不超过 100 mm，对应约 0.153 mm。100 mm 是为检验假设声明的范围，不是已测量的标定误差。
7. 相对旋转为零时，`||t_A|| = ||t_B||` 完全不依赖固定手眼旋转和平移。非零时，长度差需额外考虑 `2 sin(θ/2)||t_X||`，以及相机、编码量化和重复性误差。程序分别给出这些量，不用单一阈值自动宣布校准通过。

在这台 URDF 上，理想 ±4° 的两个端点之间产生约 31.36 mm 平移；实际 SDK 45 个刻度对应 ±3.955°，稍小。端点间差分比单边约 15.7 mm 更有辨识力。如果实际对转仍出现超出旋转泄漏及测量散布的板位置漂移，固定手眼平移假设就更难成立。若相机/FK 平移长度不一致，则任何固定刚体手眼都无法解释这个差异，需检验链节/关节真实运动与相机度量。

随后只需一个经当前路径验证的 **J4 或 J6 非平行轴** 姿态组作为留出检验，以补足固定平移的第三个方向。该动作需实际视野与几何允许；不要用继续增加相近平行 J5 小步次数替代方向覆盖。

## 旧 J3 姿态上的候选器几何回放

此项只读旧袋文件，不构造当前执行凭据。使用 J3 出向后的 `return_original_sdk_geometry.json` 和该图像前最近的真实 SDK 记录：

- 全 ±4.8° 矩形共 3,267 个几何样本，最差板边距 **−22.273 px**，出现在 J2/J3 同向 `+4.8°/+4.8°`；349 个样本视野不合格。最小 CAD 平面净距为 56.13 mm。
- 名义 ±2°/±3°/±4° 四段的最小板边距为 **48.90 / 41.15 / 33.94 px**，最小净距均为 92.45 mm。全方形中的同向极值不是理想对转必经路径，但独立轴滞后仍要求每段二维范围验证。
- 由于旧 SDK 相对实际反馈已有偏置，45 刻度反向目标使 J3 超过原 measured `+4.8°` 上界约 **0.034°**，所以该姿态下 4° 候选即使缩成有向区间仍应拒绝。2°/3° 目标本身在原绝对界内。
