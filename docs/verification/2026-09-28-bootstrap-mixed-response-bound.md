# 显式初始同步：连续混合关节响应的几何界

修复 `.runtime/bounded_joint_response_diagnostic.py` 的显式初始同步。逐单轴采样无法证明六轴混合响应满足几何要求，即使反馈使用六轴总 L1 界也不成立。新增 `.runtime/bootstrap_mixed_geometry.py`，在原 MoveIt 路径采样之前证明整个六轴 L1 球，并在发布前的最新板观测上再次证明。代码不改变使能、停止、重试策略或 2°/4.8° 反馈界；默认 4.8° 不变，需要显式选择 2°。普通往返路径未改。

证明以本次实际 URDF、当前手眼、当前相机模型、固定板平面和测得夹爪开度为条件；不证明标定准确性、全机械臂混合响应碰撞或硬件必然停在界内。实际反馈超过界仍立即禁止后续命令，不会发送停止或去使能命令。

## 连续界

令关节响应 `delta` 满足 `sum(abs(delta)) <= rho`。

- CAD 每个角点的各轴全姿态运动半径由 `SerialUrdfFk.corner_motion_radii` 给出。沿 `q0 + t*delta` 积分，角点位移不超过 `rho * max(R_i)`。从名义平面净空减去这个值，再扣 1 nm 数值余量，得到整个 L1 球中的净空下界；仍要求至少 40 mm。
- 固定板点 `P` 在相机坐标中为 `b(q) = C(q)^-1 P`。对第 i 轴，其导数范数等于该关节轴到 P 的垂直距离。轴方向变化不超过 `2*sin(rho/2)`，轴原点位移不超过 `rho * prefix_link_length`。把二者加入名义垂直半径，得到整个球中导数上界；乘 rho 积分得到 b 的连续位移界。
- 整块板为四角的凸包，坐标极值和上述凸导数上界由四角控制。将名义整板坐标包围盒扩大该位移界，包含任意混合响应下板的所有内点和边界，不仅四角采样。正前深度下界仍至少 120 mm。
- 将该完整三维区间经过 SDK 2.56.5 的投影多项式做逐运算外向区间传播。区间还向 float32 的外侧相邻值扩张，覆盖 SDK float 运算。inverse/modified Brown 的切向项使用径向缩放后的 x/y，r2 保持原值，公式依据 [官方 v2.56.5 实现](https://github.com/IntelRealSense/librealsense/blob/v2.56.5/src/rs.cpp#L3699-L3755)。不支持的模型或 SDK 版本拒绝，不静默改用针孔投影。完整像素区间距图像边界仍至少 20 px。
- `q0 +/- rho` 必须同时满足当前参数和 URDF 的各轴限制。原 13 条、每条 17 点的 MoveIt 实际场景检查保留，明确仅为其采样路径证据，不伪称它证明混合球内的全臂碰撞。

## 离线验证

首版 98 项通过，覆盖新增混合几何、初始同步界和已有 J3 行为。用实际项目 URDF、独立混合边界/内点、真实 SDK 纯投影函数验证结果包含关系；用串联 Z/X 旋转构造所有单轴射线均无位移但混合响应越过平面的反例。另测试 20 px 边界、40 mm 平面拒绝、关节限制、非刚体/非有限值、未知模型、SDK 版本及最新板观测二次证明失败时绝不发布。

历史 J3 `bounded_joint3_response_20260928T110035Z_26293/baseline_geometry.json` 的离线评估：2° 连续界下平面净空下界 61.227 mm、完整棋盘边缘下界 30.752 px、板深度下界 205.253 mm；4.8° 净空下界 27.482 mm、边缘下界 -182.899 px，因此拒绝。该结果只说明保守界在一组历史几何上可行，不能作为新 epoch 的运动许可。执行入口每次必须重新采集并重新证明。

本次实现和测试未执行任何 ROS 命令、节点控制或硬件运动。


## 当前姿态的逐坐标 Taylor 收紧（不缩小 2° 响应范围）

新 epoch 的 `bounded_joint_response_20260928T121554Z_28470/bootstrap_presync_geometry.json` 在任何发布之前被首版界拒绝：净空 68.501 mm 合格，但对所有相机坐标统一使用位移范数，整板边缘下界仅 9.695 px。没有从拒绝结果推断实际姿态危险，也没有缩小实际反馈限值。

现在的板投影使用逐坐标 Taylor 区间：`J_i = -R_camera.T [axis_i × (P - origin_i)]`，第 k 坐标的一阶变化界为 `rho * max_i |J_ki|`。展开逆串联链，`C(q)^-1 P` 是若干被旋转的常向量之和；每项中的每个关节旋转只出现一次。固定旋转、一次旋转导数、同轴二次导数和跨轴二次导数的算子范数均不大于 1。因此每个 Hessian 元素的向量范数以 `S(P) = |P| + sum(|URDF origin translations|) + |X translation|` 为全局界。L1 球中的每坐标余项不超过 `0.5 * S(P) * rho²`。这个余项在整个球内成立，包含重复轴和跨轴项。

每个板角分别计算精确名义坐标和一阶界，再加该二阶余项。对任一固定 q，板内部点仍是这些角点的同一凸组合，因此取角点区间的各坐标上下界包含整块板。之后仍使用原完整 SDK 区间投影，不把角点的投影检查误当成整板证明。

同一 fresh 几何的 2° L1 球结果：平面净空下界 **68.501 mm**、整板边缘下界 **40.046 px**、深度下界 **226.783 mm**；二阶余项最大 **0.887 mm**。不需要额外板网格细分，也没有改变任何物理门。

新增 `certify_local_cell_geometry(fk, gripper, measured7, geometry, lower6, upper6, l1_radius_deg)` 纯 API，只接受 `0 < radius <= 2°`，供离线局部网格使用。调用方必须把完整 cell 的各轴半宽和实际允许的未编辑轴误差纳入 L1 半径，并独立保留新鲜场景、MoveIt、控制权和反馈约束；API 本身不授权运动。原 `mixed_sync_geometry` 仍只允许 2°/4.8°，CLI 不增加任意运动界选项。

**113 项离线回归通过。** 新增验证包括：用独立 FK 中心差分核对全部 Jacobian 分量，在多个姿态核对重复/混合二阶项，检查 0.05°/0.5°/2° 多轴边界上的向量 Taylor 余项，以及小cell API正负边界。原夹爪净空与整板 SDK 投影测试保持通过。本次改动没有发布 ROS 命令。

## 逐 cell／逐板角的正深度归一化投影

为消除先合并 XYZ 区间造成的透视分母混用，新增 `projection_corner_boxes(model, lower_4x3, upper_4x3)` 和向量化 `projection_corner_box_batch(model, lower_Nx4x3, upper_Nx4x3)`；输入是 camera_link 坐标。Taylor 输出增加 `corner_lower_xyz_m`、`corner_upper_xyz_m`，旧接口保持兼容。

先分别对每个 cell 的每个板角做严格正深度除法区间，之后才合并 normalized x/y 域，再计算一次原 SDK Brown 外向区间。在固定姿态下，板内点是角点的凸组合，归一化后的权重变成原权重乘角点正深度再归一化，仍非负且和为 1。因此 normalized 整板都在 normalized 四角凸包中；证明覆盖板内部，不等于只投影四个角点。

所有除法、乘法的数组运算都向外包含 float32 舍入。126 项 helper/base/J3 离线测试通过，包括倾斜整板的随机凸组合内点、真实 SDK 像素包含关系，以及 37 个 cell 的向量化归一化与逐个标量区间结果逐位一致。不同 cell 的同一角也不能预先合并 XYZ，最终批 API保留 `[N,4,3]` 到归一化之后。
