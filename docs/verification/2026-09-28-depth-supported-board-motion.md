# 2026-09-28 不使用格长的深度支持角点运动诊断

已实现并验证独立的深度支持 ChArUco 运动工具。它能把“假设标定板格长 15 mm 的 RGB-PnP”与“不使用该格长的深度米制重建”分开，但目前单帧深度平面也有约毫米级相对位姿不确定性，不能作为相机/机械臂的外部真值，更不能据此直接改格长或 TF。

实现为 `.runtime/analyze_depth_supported_board_motion.py`；只读取已关闭的袋文件和几何快照，不启动 ROS 节点，不调用服务，不修改生产代码或参数。输出仅允许写已挂载的 SanStand。

## 重建如何独立于 15 mm

1. 对同源 RGB 检测 12×9、`DICT_5X5_100` ChArUco 角点 ID。检测板以 **1 个无量纲格长**、0.75 marker 比例构造，保持原 legacy pattern 和 1.5 倍检测缩放。
2. 用检测像素的凸包、向内 4 px 的腐蚀范围选择原 Z16 深度；这个 ROI 不使用 PnP 位姿、PnP 深度或毫米板边界。深度与颜色使用相同的运行时几何射线；若内参不匹配则拒绝，不隐式忽略外参。
3. 通过归档 SDK 参数反投影 Z16，固定 1.5 mm RANSAC 阈值拟合板内部平面；按 16 px 空间棋盘块分训练与留出点，报告双方误差及有效深度比例。
4. 将每个角点的 SDK 射线与深度平面求交，得到相机光学系下的米制 3D 点。
5. 两帧取相同 ID 的角点，用 Kabsch 估计刚体运动，并与归档 PnP 以及 accepted FK 经原手眼表达的相机运动比较。报告共同 ID 数、二维覆盖、3D 刚体残差和跨帧像素残差。
6. 最后才用无量纲 ID 格坐标与米制 3D 点估计格距，并与 15 mm 作诊断比较；15 mm 从未用于深度 3D 点的构造。

在旧 J2 六个 RGB 快照上，将检测板单位从 1 改为 0.015 后，相同 ID 的像素 RMS 改变量仅约 **0.0000023–0.0000070 px**，验证检测不依赖绝对格长。不是用该结果宣称传感器精度达到这个数值。

同一出向停稳窗口的另一帧，深度估计转角为 1.708°，相对 FK 的平移向量差则为 0.976 mm。深度模式某一项更接近 FK，不足以证明它更接近物理真实值。

深度支持的相似格距为 **15.184–15.195 mm**，比 15 mm 约大 1.23%–1.30%；二维格点的相似模型残差仍有 0.335–0.401 mm，不能把这些点当作理想均匀棋盘。独立深度平面与 PnP 法向相差 **0.886–1.056°**，角点光轴深度的中位差约 **2.894–3.054 mm**。法向差说明两模式不只是一个统一比例尺度的差别。

这个结果不能区分“实际印刷格距稍大”与“深度尺度/表面倾角/注册/相机射线的系统误差”。用户确认板平整固定，但物理格长尚无独立计量，因此不能自动把 square_length 改成 15.19 mm。返回相同 accepted 角度时，两个模式估计的运动还不同，也不能只用其中一幅图把剩余误差归因于机械臂。

## 本次新 epoch 的 J5 记录

源目录：`bounded_joint_response_20260928T122338Z_47349`。只在这个新会话内部比较；首次同步前的照片不混入往返基线。

基线到出向停稳：70 个共同 ID，深度刚体 RMS 0.099 mm、跨帧像素 RMS 0.128 px。深度/PnP/FK 的运动角为 **1.319° / 1.377° / 1.494°**，相机平移长度为 **2.932 / 2.680 / 2.910 mm**。对应深度−FK、PnP−FK 平移向量差范数为 **0.290 / 0.329 mm**。

基线到返回停稳：70 个共同 ID，深度刚体 RMS 0.234 mm，跨帧像素 RMS 0.275 px。实际 J5 相对基线增加一个编码刻度；深度/PnP/FK 的运动角为 **0.127° / 0.073° / 0.088°**，平移长度为 **0.910 / 0.435 / 0.171 mm**。深度−FK 与 PnP−FK 向量差范数为 **1.031 / 0.546 mm**，深度与 PnP 相互差 **0.640 mm**。

由此，这批单帧深度结果不能裁判之前约 0.8 mm 返回板位移究竟来自真实机构、PnP 还是深度误差。小的角点刚体残差也不保证相机运动本身准确：整个深度平面的共同倾斜或偏置会让全部点一起发生近似刚体变化，Kabsch 残差不会揭示这种共同误差。

## 新联动实验的工具接口

工具支持 `/bounded_response/snapshot_rgb`、`/bounded_joint23/paired_rgb` 及原 Z16 主题。加 `--paired-stream` 后，从归档 provenance、quality、精确同 source 的 board TF 和 accepted 反馈恢复每个阶段最多 8 个均匀分布的帧，仍要求：

- quality 与 TF 接收时的来源年龄均不超过 350 ms；
- 相机与最近 accepted 来源差不超过 100 ms；
- 前后覆盖 0.8 s 的独立静止窗口，关节峰峰值不超过 0.15°；
- 相同 epoch、相同模型 fingerprint 与有效的角点质量。

不合格或缺少精确 RGB/Z16 的帧明确记为缺失。归档帧的较晚写盘时间不能变成新的图像来源时间，恢复出的离线元数据不能作为执行几何。多帧结果仍需按时间窗口汇总并报告真实散布，不能把所有角点和帧对当作独立样本夸大置信度。

运行示例（不执行运动）：

```bash
source devel/setup.bash
tools/with_local_realsense_sdk.sh /usr/bin/python3 \
  .runtime/analyze_depth_supported_board_motion.py <已关闭实验目录> \
  --output <SanStand上的分析目录> --paired-stream
```

横纵邻接边的中位数比例与全局回归不完全相同，完整各帧数据已保存。例如旧 J2 基线邻接比例 1.002755，出向停稳 1.004621，返回 1.000844；新 J5 则为 1.002482 / 1.006120 / 1.001516。不同 ID 覆盖与局部噪声会影响短边中位数，因此不能只挑一个比例当作印刷长宽比。

深度支持的点阵呈现约 0.1%–0.46% 的横纵差，并有约 0.4°–0.6° 的非正交夹角；它不仅是前面合并格距的统一尺度偏差。但这还不能判定纸面印刷非等比或剪切。固定深度点云中心、仅将深度平面法向围绕光学 X/Y 扰动 ±0.5°，旧 J2 基线的 X/Y 即可变为 **0.99828–1.00704**，新 J5 基线为 **0.99835–1.00793**；这一敏感度范围覆盖当前观测差异，而原 depth/PnP 法向差已有约 1°。

仅改变角点空间覆盖、每次去掉一个象限，旧 J2 返回的回归比例也在 0.99918–1.00279，新 J5 返回在 0.99854–1.00330 之间变化。该留出测试与法向扰动都是敏感度分析，不是对真实板形状的置信区间。各行/列与相邻边共用同一个拟合深度平面，不能当作彼此独立的外部测量。

**5 项新增合成测试通过**：非等比 X/Y 在任意刚体姿态下恢复、剪切与尺度分离、统一尺度保持转角/轴比、仅法向误差产生表观非等比、缺少第二维时拒绝。结果归档在 `pose_chain_identifiability/depth_grid_j2/` 和 `depth_grid_new_j5/`。保持现有 square_length、K 和 X 不变。
