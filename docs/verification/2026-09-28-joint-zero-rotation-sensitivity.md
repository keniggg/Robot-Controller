# 2026-09-28 内部关节零位的相对转角敏感性

仅用昨日预留的 **22 个训练窗口**拟合内部零位后，昨日独立验证集的转角残差有所下降，但今天更大姿态范围的任务集总体没有改善。这个零位模型只能部分解释关键 14→20 姿态对，不能写入 URDF 或控制器。

实现：`.runtime/audit_joint_zero_rotation_sensitivity.py`。数据从当前恢复目录 `camera_intrinsics_sensitivity/detected_rays.json` 的 55 个 capture 索引读取，accepted q 来自每个原始 `capture.json` 的精确 source 帧；相机旋转使用**未修改 SDK 射线**的 baseline PnP，不使用四参数相机候选。各组使用各自归档的 URDF。重建 FK 与归档 tool 旋转的最大差为 0.00000242°，未观察到足以解释残差的 FK 读取差异。

## 可辨识量与拟合约束

目标为同一固定板 dataset、同一 driver epoch 内的 `camera_relative_angle − FK_relative_angle`。这是不依赖固定手眼 X 的标量不变量；只使用名义 FK 转角不少于 2° 的姿态对。

只拟合三个诊断参数，全部限制在 ±15°：

- J2+J3 的零位和，数学实现时加在 J2 上；两轴平行，旋转数据不能分别辨识两个零位。
- J4 零位。
- J5 零位。

J1 的共同零位可吸收为 base 全局旋转，J6 的共同零位可吸收为末端/手眼旋转；相对转角不能辨识，因此没有拟合。没有同时拟合角度比例、轴方向、手眼、内参或板形状。

## 稳定性与非唯一性

7 个优化初值均收敛到相同训练极小值，没有撞到 ±15° 边界；这只说明当前目标的数值求解重复性，不说明物理参数已唯一确定。`soft_l1`（0.05°尺度）诊断解为 `[−7.900°, −0.733°, −1.555°]`，今日任务 RMS 约 0.214°，仍只有有限改善。

逐个去掉一个训练 capture 后，参数范围：

- J2+J3：−8.491° 至 −7.484°；
- J4：−2.200° 至 +0.756°；
- J5：−1.514° 至 −0.832°。

按 capture 分成 4 组留出，J4 候选可变化到 −4.138° 至 +2.808°，其中一组真正留出 RMS 从 0.231° **变差到 0.247°**。这比仅看训练矩阵条件数更直接地显示其姿态覆盖敏感性。留出与逐 capture 排除是敏感性诊断，不是外部精度置信区间。

这种 X 无关的相对角偏差可能由内部零位、角度比例、实际轴倾斜、变形、相机/PnP 或板几何产生。现有拟合不能把差异唯一归因于某一个编码器；更没有验证末端位置、抓取高度或闭爪结果。尤其 −7.9° 的中间零位和若直接写入位置 FK，会产生另外的位移影响，本轮未证明它正确，因此不部署。

## 验证与归档

**5 项数学测试通过**：J2/J3 零位和不可分、J1 全局零位不改变相对角、J6 末端零位不改变相对角、任意手眼下恢复已知合成内部零位、跨固定板 dataset/epoch 不配对。
