# 电机邻近桌面与固定板的同源诊断

本轮针对实际电机附近的红色桌垫表面，独立拟合深度平面；不是把标定板平面当作抓取支撑面。没有发布动作、切换目标、替换手眼、清除旧故障或提供接触许可。

用户现场照片显示底座下有鼠标垫、桌边有夹具；用户随后明确机械臂已固定死。按已牢固固定记录，没有证据认定软垫造成10–11 mm抓取偏差，不要求用户据此改变布置。仅凭腕上相机和关节编码器也不能唯一分离底座刚体变化与内部姿态链误差。

## 数据与方法

`.runtime/audit_motor_adjacent_table.py` 从已结束J4、J6和J2/J3反向转角实验提取40帧。RGB、Z16、ChArUco quality与板TF必须源时间完全一致；沿用350 ms接收年龄、当前模型指纹/epoch和独立实际关节停稳验证。每个静止阶段均匀选5帧，跨帧对照是相关的描述性统计，不是25次独立实验。

人工审阅J6基线图确认电机候选在(267,155)附近。该像素仅用于固定板坐标中的区域种子，不是生产target track ID。随后每帧使用当前SDK inverse-Brown射线反投影。电机周围22–55 mm环形区域排除完整180×135 mm板及其6 mm周边，再以深度独立拟合支撑平面；要求至少100点、70%内点、2 mm残差门和至少三个象限覆盖。平面朝向相机，电机候选点位于平面上3–40 mm及23 mm平面半径内。保存RGB叠图、源像素、原始点、mask、三种坐标表达及拟合结果。

已人工查看叠图：绿色拟合点在电机旁红色桌垫，品红点覆盖电机可见表面，标定板被排除。首轮法向按板正Z设定导致全部电机正高度拒绝；该拒绝记录保留在`motor_adjacent_table/`。后续明确将桌面法向朝向相机，结果另存`motor_adjacent_table_normal_oriented/`，未替换首轮记录。

## 当前结果

| 动作 | 桌面在板坐标中局部距离变化中位数 | 桌面在accepted-FK base中变化中位数 |
| --- | ---: | ---: |
| J4去程 | +0.248 mm | +0.290 mm |
| J4回原SDK | +0.470 mm | +0.497 mm |
| J6去程 | +0.353 mm | +0.390 mm |
| J6回原SDK | +0.033 mm | +0.098 mm |
| J2/J3正向抵消转角 | −0.178 mm | +0.192 mm |

单帧平面RMS约0.79–1.02 mm，跨帧差的范围约±1 mm，不能把上述亚毫米中位数解释为外部精密计量。电机可见表面高度中位约8.0–8.4 mm，90百分位约12.6–13.2 mm；这是可见表面统计，不是电机总高度、完整质心或抓取接触高度。

J2/J3去程虽整体板位姿有约0.9 mm apparent漂移，邻近桌面高度在板坐标中未出现同量级系统跳变。小角度结果不能外推为已覆盖最终接触姿态，也不能据此下移固定10 mm。原10–11 mm跨大姿态支撑矛盾仍未关闭。

## 后续使用边界

此证据仍是人工种子定位的诊断，未证明与重启前生产目标track的严格身份绑定。重启后实际selection为新epoch的generation 1，tracker尚未初次锁定电机（no_center_instance）；不得假称沿用旧track。后续应显式关联旧失败记录、新epoch的新鲜唯一识别及局部证据，再生成新计划。新计划不能借较新时间戳隐去旧故障，也不能沿用旧碰撞许可。

固定手眼仍为2026-09-27验证通过那组。SDK与legacy针孔在电机附近相差约0.43 mm；旧接近/闭合记录的约11 mm矛盾仅改变约0.01–0.02 mm，不能单独解释空抓。J2/J3相机位移7.384 mm与FK 7.663 mm的差也落在两端各半个编码字的量化情景包络[7.181,8.193] mm内，不能直接归因连杆长度错误。
