# 非平行腕轴与独立深度角点复核（2026-09-28）

结论：J4/J6 新动作补足了原 J2/J3/J5 近乎平行的激励。它们在未修改 X 下的板位移仅约 0.1–0.2 mm，而旧三轴得到的大幅固定平移修正使新腕轴留出明显变坏，不能上线。J4 相机转角和 actual FK 基本相容；J6 留有约 0.05–0.08° 的小角度差，独立 depth 平面产生的角点也观察到同向差，但共享 RGB 像素及 SDK rays，不能据此直接定责编码器或相机。

## 数据和来源

- J4：`ros_log/bounded_wrist_response_diagnostic_20260928T125306Z_126028`
- J6：`ros_log/bounded_wrist_response_diagnostic_20260928T125421Z_130257`
- 每袋只比较自身固定板的 baseline、outbound 和 return；没有把旧、新布板的绝对板坐标相减。
- 实际反馈出向均 +1.669921875°。原 SDK 字返回后，J4 比初始 actual −0.17578125°，J6 比初始 actual +0.263671875°；原命令返回不能说成完全回到原实际姿态。
- 四个已停稳的 3 秒窗口中，全部 actual 关节反馈峰峰值为 0，SDK 字恒定。这只覆盖停稳后，不否定此前运动结束时的摆动现象。

分析器兼容新 `/bounded_wrist/paired_rgb` 和 `/bounded_wrist/pair_provenance`。源质量/板 TF 需同 stamp、接收延迟 <=350 ms，反馈关联 <=100 ms，独立 ±0.4 s 反馈窗口 >=6 样本、最大间隔 <=250 ms、关节峰峰值 <=0.15°，相机模型和 epoch 一致。exact RGB 与 quality/TF-only 统计分开。

## 格距与平面法向敏感度

对每帧独立保存水平/垂直邻接角点、各行/列回归和二维仿射格距。J4 三阶段仿射 X/Y 格距比中位为 1.001917 / 1.001384 / 1.002719；J6 为 1.002361 / 1.002413 / 1.002222。X 格距约 15.196–15.204 mm，Y 约 15.160–15.179 mm，轴夹角约 90.49–90.56°。但只让深度平面法向绕 optical x/y 扰动 ±0.5°，各阶段 X/Y 比范围可覆盖约 0.9956–1.0084，包含 1 及当前估计。共享平面法向、深度尺度与相机射线误差不能被角点数量平均掉；现有数据不能确认印刷非等比，也不修改板模型。

## 单一固定手眼平移假设的非平行留出

统一使用每个会话自身的板位移，每 0.5 秒时间块等权；X 旋转不变，只诊断三个工具坐标平移参数。旧三轴 condition=41.72，全五轴 condition=1.57037，观测条件明显改善。

旧 J2/J3/J5 板中心拟合 δ=[13.2168,−83.3392,−14.6766] mm，在新 J4/J6 上使板中心位移由 0.178/0.114 mm 恶化为 2.384/2.485 mm。全部五轴拟合 δ=[9.1005,−0.7069,−12.5307] mm 后，J5/J2/J3/J4/J6 残差为 0.424/0.450/0.383/0.111/0.376 mm，仍使原本稳定的 J5/J6 变坏。

根代理另做严格留出：只训练旧 J2/J3/J5 + 新 J4，J6 不参与，板中心 δ=[12.4885,−1.7209,−12.9692] mm、condition=2.01。J2 .910→.347 mm、J3 .709→.387 mm，但 J5 .059→.480 mm、J6 留出 .114→.476 mm。板原点结果相近。该结果见 `nonparallel_translation_audit/report.json`，进一步拒绝把局部误差直接写成全局 X 修正。
