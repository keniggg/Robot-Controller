# 动作停稳修复与姿态链误差诊断

本轮将动作结束后的摆动与停稳后的跨姿态偏差分别处理。软件回归通过不代表实体摆动消失或抓取成功；没有添加固定向下 13 mm 偏置，没有替换当前内参或手眼参数。

## 已修复并验证的任务完成判据

原 `_wait_for_motion_settle` 轮询 `/joint_states`，比较相邻轮询值。重复缓存、每步很小但持续累计的漂移、轮询间摆动，都可能被误判。原 0.8 秒是总等待时间，不是完整稳定窗口。legacy 非 rich-plan 三处还忽略了该函数的失败结果。

现在复用 `/alicia_d/accepted_joint_states` 历史，要求动作返回后的完整 0.8 秒独立源反馈，同一控制代次，源戳递增、反馈新鲜、样本间隔不超过 0.25 秒，六轴全窗口峰峰值不超过原 0.0025 rad。失败结果均被调用方处理。正常静止不再额外等待三轮缓存计数。未改变运动速度、位置容差或接触几何门限。

任务相关 321 项离线回归通过，其中新增 15 项。刚采集的稳定窗口包含 10 个独立 accepted 样本、跨度约 0.890 秒，判定通过。9 月 20 日真实固定 SDK 目标下的腕部摆动 bag，动作完成后 5.1 秒中有 51 帧 accepted、45 次固定 SDK 发送；可评估的 43 个窗口全部被拒绝。此次回放不等于重新执行了历史运动。

## 驱动响应方向的有限修复

发现一个可离线复现的问题：响应探测已开始时，目标反向，原实现仍等待原方向，可能误报 `ENCODER_RESPONSE_LOST`。修复仅在 SDK 反向位移达到原 0.02 rad 门限、目标明确越过当前实测且剩余位移也达到该门限时，更新该轴的响应基准和方向。要求指令之后、原探测截止时间之前的新反馈；重复反向不能延长截止时间。

复核时发现“绝对目标减编码器基线”的全局符号检查会破坏原有固定跟随偏差下的增量响应契约，因此未保留该全局检查。目标回撤但未满足明确跨越条件时，保持原位移判断。正向使能、重连同步、保护和初始探测失败处理未改动。最终 124 项 C++ 测试全部通过，包括正负固定跟随偏差、反向响应、截止时间和新鲜反馈用例；最终版本已构建并随本次完整 ROS 启动加载。命令、文件哈希和结果摘要见外盘 `driver_regression_summary.json`。

尚无本次完整高频 SDK 记录证明该缺陷触发了用户描述的这次摆动。9 月 20 日在 47 条完全相同的 SDK 目标下，J5 原始编码器仍摆动约 1.318°，说明历史上还存在目标保持不变时的实际反馈摆动。不能据此诊断具体 PID 参数、硬件损坏或固件算法。

## 不依赖手眼参数的几何证据

33 个窗口、498 帧中，每个窗口的六关节 accepted 值均完全不变。同一控制代次、近实测姿态的 13 个配对，标定板坐标差为 0.100～0.706 mm；这些是相近姿态，不是精确重复角度。此前固定参考的跨姿态最大误差仍为 5.572 / 6.144 mm。

对固定标定板，令 `A = inverse(T_base_tool_i) * T_base_tool_j`，`B = T_camera_board_i * inverse(T_camera_board_j)`，应满足 `A X = X B`。两者旋转角相同这一条件与手眼参数 X 无关。

同代次 `capture_014 → capture_020` 的 FK 转角为 13.4623°，相机观测转角为 14.1732°；20×10 个原始帧配对的差全部在 0.7020～0.7434°。因此数据包含固定刚性手眼变换无法消除的不一致。候选来源包括相机 PnP/标定板几何、关节/FK 模型、相机安装或结构随姿态变化；不能据此单独归责手眼，也不能证明该角度差独自造成全部平移偏差。

本轮使用实测关节 FK，不能把指令与反馈约 1° 的静差直接再算成手眼误差。采样的关节与图像时间差约 ±96 ms，但稳定窗口内 FK 不变，普通运动延迟不足以解释本次稳定偏差。

## 旧配置曾成功抓取的含义

历史上确有夹住并提起物体的记录。一次成功表示物体落入了实际夹持范围，不代表相机到机械臂整条坐标链全域准确。不同物体大小、夹持余量和姿态会改变误差容忍度。旧内参、用旧内参估计的手眼和机器人模型误差在局部可能部分抵消；这是可能机制，尚无同物体、同姿态、同执行代码的受控 A/B 实验证明。

旧 D405 SDK 的投影问题已有独立同场景证据，新 SDK 桌垫评估窗的高度中位误差从约 9.995 mm 降至 1.302 mm。旧配置抓取过不能推导出旧内参更准确，也不足以支持直接回退。相关证据见 `2026-09-23-d405-sdk-projection-repair.md`。
