本报告只读取已闭合记录，没有硬件操作、生产代码修改、自动 J4 补偿或门限放宽。用户随后明确机械臂电源已关闭，所有实机动作和在线模型加载验证均暂停；本轮继续工作仅限离线分析及文档。旧 epoch/SDK 末值只保留为历史证据。恢复供电后必须从新鲜反馈重新建立上下文，不能沿用旧执行许可或修改脚本 pins 让它自动跟随。

## 旧 J4 边界没有重置

仍固定原失败 session 的 anchor：J4=2049 字，即 +0.087890625°，永久区间为 `[-0.312109375°, +0.487890625°]`。新动作中最大旧-anchor 偏移为 3 字，即 0.263671875°，小于原 .4°；相对新起点的 J4 最大位移为 2 字，即 0.17578125°。其他未编辑 J1/J2/J5/J6 全部没有变码。

记录中的首次临发布重证仍为：CAD 净距至少 65.964 mm、全板边距至少 37.877 px、深度至少 237.104 mm；没有降低原 40 mm / 20 px / 120 mm 门限。SDK 名义桥接与实际完整响应域继续分开证明。

在袋末 J4=2046 的这个姿态，对旧 anchor 下侧只剩 1 个整字的余量：2045 仍在界内，2044 即再次超界。因此不能以这次通过为理由，从该末点自动连续重复 +8 或回到 +22。下一次任何动作都需要新鲜实际状态和独立证明；本报告不把袋末状态当作现在的实时状态。

## 现有数据能支持的解释

J4 在两段动作前静止记录中保持 0°；J3 小输入后产生 −0.17578125° 的偏移，并在观察的随后 63.4 s 内保持。这表明本次记录包含持续的跟随残差/姿态相关偏移候选，不能只用“一个瞬态过冲后回到原位”解释。记录没有显示本次 J4 往复摆动。机械载荷、摩擦/回差、结构弹性、伺服静态误差及内部反馈误差仍未被独立区分。

不能直接把旧 +22 的 5 字 J4 越界峰值与新 +8 的 2 字峰值作为输入速率对照：两次起点、SDK 偏差、J3 终点及历史状态不同；旧袋在越界后关闭，还缺少紧邻动作的完整衰减轨迹。当前只能说较小输入这一次没有越界。

静止基线 raw 状态包含 E1×20、E2×2；动作相关独立袋包含 E1×34、E2×3。状态字在无动作时也出现，因此不能据其出现直接归因本次响应。温度记录与通道映射的既有限制保留，仅作为诊断附件，不据此调参或推定实际热故障。

## 后续输入设计：何时需要同端点比较

若目的只是记录这一次有限输入是否通过，当前证据已经足够。若要进一步区分阶跃输入引起的动态响应与姿态/载荷导致的持续偏移，需要同起点、相同 SDK 偏差、相同最终目标而输入时间分布不同的独立对照；目前没有这组证据。

以下 SDK 数值仅描述历史对照条件，不是恢复供电后的待执行目标。新 epoch 下需要另行定义与审查输入及起点，旧固定 epoch 脚本不能直接继续。最小有辨识力的对照应预先固定：

1. 基准的 actual 与 SDK、J4 旧 anchor、epoch 和完整几何。进入起点本身也必须独立通过原界限，不能为做对照自动返回，不能把新起点重置成放宽后的旧 J4 界限。
2. 两种输入相同的最终 SDK 字。已有 A 为 1991→1999 一次变化；B 可离线评估固定单调分段序列（例如 1993→1995→1997→1999）及预声明总时长。B 属于新的有限协议，不能循环调用当前“一次命令”脚本来实现，更不能把未达到目标变成重试或无限补偿。具体序列、时间和每次发布条件必须另行审查，不在本轮实施，也不改全局驱动参数。
3. 两组都持续记录原始反馈和每一次成功 SDK 写入，至最终至少 0.8 s 独立停稳、3 s post-hold，并保留独立记录器的较长被动尾段。J4 旧-anchor/held 界限、反向 .5°、绝对4.8°以及原几何限制全部不变，任何失败都保持失败并只被动继续记录。
4. 比较 J4 最大偏移、超过最终偏移的部分、方向反转次数、到达最终编码稳定区间的时间、最终 J3/J4 实际位置及 SDK 残差。相同 SDK 终点不保证相同实际终点；若终态 actual J3 不同，不能把 J4 差别仅归因输入平滑度，也不能自动追加命令强迫匹配。

若在可比终态下，平滑输入只降低 J4 的短时峰值而最终偏移相近，才增强动态分量解释；若最终偏移主要随实际姿态保留，则增强持续载荷/静态跟随误差解释。两者可能同时存在，任何一个结果都不能单独确诊机械回差。

当前缺少同端点平滑对照、同条件重复性、旧 +22 后连续恢复轨迹、亚采样周期运动信息，以及独立于控制器的关节/载荷测量。现有记录不足以拟合 J4 自动补偿、调整 PID、更新运动学零位或放宽旧 bound。若匹配起点与输入范围不能在旧边界内证明，应保留未辨识结论，而不是扩大边界取得样本。
