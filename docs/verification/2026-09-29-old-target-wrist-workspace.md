`||J5−J2|| ≤ ||a3|| + ||a4+R4*a5_parallel|| + ||a5−a5_parallel|| = 446.318 mm`。

该上界允许所有关节角，忽略实际关节限位。因此超过它的姿态即使放开限位也不能到达；没有放宽实际规划限位。

对于固定的工具位姿 `(p,R)`，由于 Joint6 后的固定旋转为单位阵：

`p_J5 = p − R*[t_tool + Rot(u6,−q6)*R6ᵀ*a6]`。
