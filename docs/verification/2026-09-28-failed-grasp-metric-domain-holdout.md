# 抓取大动作留出：固定零位/手眼模型的训练域检验

本次只做离线计算，无 ROS 连接、参数部署、相机内参/尺寸/尺度修改。原 22 帧候选未解释该失败域；扩域 45 帧候选的离线数值支持进入独立实机验证，但尚不能描述为真实抓取已经修复。

## 先检验原冻结候选

原 22 帧训练得到的 10 参数候选固定不变，复算 08:42 真正空抓实验的原始共视桌面。保持原像素选择、平面拟合、内点和 actual q；用存档 T_base_optical 把各平面还原到相机坐标，再用候选 FK(q+offset) × X 投回 base。共同锚点随初始图像变换，未按候选重新挑选区域。

原闭爪前 50/80/100 mm 区域的 later−initial 高度差为 −9.943/−10.009/−9.974 mm，原 22 帧候选得到 +7.566/+7.508/+7.544 mm：发生反号，仍有约 7.5 mm 残差。此独立失败域明确否定该候选已经足以修复抓取。

## 一次预声明扩域

训练固定改为原 22 帧，加原 task_pose_validation 中 16、2、5 帧三个多帧组，共 45 帧。两个 singleton 不用于拟合。上述 23 个 task 样本已变为训练，不能继续称为验证。原 8 个 independent、08:42 抓取、本轮 J1 与 J2/J3 居中完全留出。

复用原 X 六自由度和 q2–q5 零位模型；q1/q6、URDF 长度、尺度、K 固定。原边界为 X 平移 ±10 mm、X 旋转 ±3°、零位 ±10°；位置权重 1 mm、旋转权重 0.1°，零初值，仅一次拟合。每个 dataset/epoch 单独固定板均值消元，未混合板移动前后的绝对坐标。相机 fingerprint、URDF、原 X 与存档 actual FK 数值匹配。

扩域训练 Jacobian rank=10、condition=20.627；8 次函数评估收敛，无参数触界。

## 原验收标准口径与下一步资格

历史验收阈值来自 `handeye_auto_20260927T102700Z/final_validation_20260927T110130Z/result.json`：位置 RMS ≤3 mm、最大 ≤5 mm，角度 RMS ≤1°、最大 ≤2°。常引用的 2.244 mm / 0.591° 是历史独立组实测最大误差，不是阈值。上表独立组自身居中 RMS 用于描述离散，不能冒充对训练固定参考的验收。

不重拟合，使用扩域候选在原 22 训练组得到的冻结板参考评估原 8 个 independent：位置 RMS **0.591864 mm**、最大 **0.822819 mm**；角 RMS **0.140173°**、最大 **0.257268°**，通过上述既有数值限。全 8 帧两两最大为板原点 1.308198 mm、板中心 1.501185 mm、转角 0.360280°。

本轮独立 J1 全 48 帧最大两两板原点/中心/转角为 0.596508 mm / 0.541633 mm / 0.112997°。J2/J3 居中全 72 帧为 2.004828 mm / 2.167745 mm / 0.233304°；相对该 session 初始停稳均值的最大误差 1.956279 mm / 0.155119°。两次 session 只各自比较，没有跨板位置比较绝对坐标。6 个抓取后阶段的 18 个原共视平面最大高度差 0.911152 mm。

因此，按既有误差限和预算，**该候选可以进入独立实机验证**。J3 等小指标相对原模型略增仍需完整保留，但不应额外要求每个指标都严格改善。这里没有补做多轮择优或把 task 训练成绩当独立验证，也未声称已完成原手眼流程的所有实机验收。
