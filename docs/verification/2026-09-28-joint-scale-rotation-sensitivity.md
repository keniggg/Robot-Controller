# 关节角尺度的独立离线假设检验（2026-09-28）

结论：不能用训练集得到的关节角比例修改驱动、URDF 或控制器。六参数比例虽然降低了昨日训练及独立验证误差，在今天抓取姿态的保留集上却明显失败。共同单一比例也不能同时解释独立验证与任务姿态。

## 数据及约束

数据、原始图像源和配对规则与 `2026-09-28-joint-zero-rotation-sensitivity.md` 完全相同：昨日 22 个训练窗口、8 个独立窗口、今日 25 个窗口（21 个可形成同会话同 epoch 的 >=2° 转角对）。对应 227 / 27 / 128 对；共享窗口的配对并非独立样本。相机使用未修改 SDK rays 的 baseline PnP，未采用相机拟合候选。

本实验保留全部零位，单独假设 `q_hypothesis[j] = gain[j] * q_recorded[j]`，gain 在 [0.9, 1.1]，不同时拟合角度零位。只用 22 个训练窗口拟合。独立验证与任务数据完全不参与参数优化。代码无 ROS 控制、参数写入及部署接口。

## 限制和验证

这里拟合的是相机转角与机械模型的相容性，不是独立测量电机编码器比例。较窄的训练姿态区间允许比例参数部分模仿中间关节零位和其他系统偏差；跨姿态保留集揭示了这种不稳定性。角度目标不验证 XYZ 高度、负载、弹性或实际抓取成功。固定手眼参数无论旋转还是平移都不改变相对旋转角不变量，不能用重算 X 消除这些角度差。

合成验证 4 项通过：恢复六个已知比例、恢复共同比例、单位比例等同原模型、错误维度拒绝。未更改线上参数。
