## 运行参数下的观测

相机 RGB 相对转角 2.68737°，实际反馈 FK 预测 2.67451°。RGB 转轴距 board 法向 2.60205°；FK 转轴距 board 法向 9.06681°。两轴差 9.69324°，配对 5–95 百分位为 8.816–10.425°。

运行坐标链推算的 base Z 距 board 法向 10.75553°。这与本次 RGB 转轴观测不同，不能单凭坐标链里的约 10° 倾角认定实体桌板/底座倾斜。用户确认底座固定牢靠；本记录不假设底座移动。

如果额外假定每个反馈字为最近舍入且真值位于半字内，单端六轴的 SO(3) 最保守累积误差界为 6×0.0439453125°；两端合计为 0.52734375°。这只是量化模型条件界，不证明编码器机械精度，也不能把当前 0.45316° 旋转残差唯一归因于某个零点或手眼错误。
