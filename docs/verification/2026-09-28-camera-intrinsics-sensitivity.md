# SDK 射线上的相机内参敏感性审计（只读）

本次以已归档原始 RGB 独立重检测角点，将 SDK 2.56.5 归一化射线映射到 fx=fy=400、cx=320、cy=240 的虚拟图像。在 22 个既有训练姿态上拟合四个 pinhole 参数，额外畸变固定为零，再看 8 个独立验证/返回姿态及今晨 25 个任务姿态。没有修改生产内参、手眼、深度尺度或关节参数。

所有 55 帧来源的相机模型指纹一致；每个采样窗口只选原先记录的 selected_frame_index，并按精确 source_stamp_ns 读取其 RGB。用相同 1.5 倍检测重算，完整像素/ID 射线归档供复核。虚拟像素 RMS 不等于原始畸变像素 RMS。这是四参数局部敏感性试验，不覆盖所有镜头模型或标定板非刚性/非等比印刷误差。

训练所得虚拟 fx/fy 为 401.2275 / 401.2499，主点为 320.0375 / 239.5493。它对关键的不依赖固定手眼的转角矛盾没有改善：任务姿态最大相机−FK转角差的绝对值，基线 0.70796°，候选 0.70867°；独立验证的最大值 0.50105°→0.49953°。训练重投影 RMS 也没有可支撑部署的独立改善：独立集单帧 RMS 中位 0.14608→0.14583 虚拟像素，任务集 0.11585→0.11596。

按姿态索引分成四组逐组留出时，虚拟 cy 在 233.56–242.03 间变化，说明这批视角对某些参数的约束较弱，不能拿全样本拟合值替换运行内参。该结果削弱了“仅微调焦距/主点便能解释全部跨姿态误差”的假设，但没有证明工厂内参绝对准确或机械臂硬件有故障。

分析脚本：`.runtime/audit_board_camera_intrinsics.py`。完整数据：当前恢复目录 `camera_intrinsics_sensitivity/{detected_rays,report}.json`。原标定/独立验证/任务姿态记录未改写；结果 local_only 保留在 SanStand。

## 固定相机射线下的板横纵比例敏感性

另以相同 22 个训练图像，仅从图像重投影残差估计板 X/Y 比例，不使用机械臂反馈、深度或验证集参与拟合。最优比为 1.0007409，四组留出训练结果 1.0004462–1.0011463；训练总平方误差仅从 31.74808 降到 31.71469 虚拟像素²。任务验证重投影 RMS 中位反而从 0.11585 增至 0.12138；关键转角差仍为 0.70784°。因此没有依据把板模型改成非等比矩形。该试验受工厂射线模型假设限制，不替代实物格长测量。脚本为 `.runtime/audit_board_aspect_sensitivity.py`，原始结果为同目录 `aspect_report.json`。
