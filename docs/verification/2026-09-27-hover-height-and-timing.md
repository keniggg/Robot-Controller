以活动内参重算：pinhole 左/右指尖净空为 10.20673 / 8.31479 mm，SDK inverse Brown 反投影为 10.18305 / 8.33243 mm（畸变影响约 -0.024 / +0.018 mm）。相对原闭爪模型仍差约 6.2 / 4.6 mm。此计算不含 base FK，仍依赖现有静态手眼和 CAD，不能据此确定该改哪个标定项或新增固定下降量。来源、审计交叉验证和敏感性见外盘 `hover_geometry_forensics.md`、`intrinsics_audit_crosscheck.json`；旧结果完整保留于 `superseded_438p6_intrinsics/`，已标注撤回。

## 高度裕度检查

增加 `contact_height_margin.py`：精确分析有限非凸指面与冻结高度带在支撑法线平移下的连续可行区间，保留原 2 mm 重叠及 3 mm 净空。分段解析处理非凸指面缺口和倾斜投影；退化或非法输入拒绝。该函数不返回推荐偏移、不改目标、不授权运动。

生产配置明确启用 `contact_height_registration_margin_enabled`，用已有 `handeye_translation_max_error_m` 作为历史经验误差的压力检查尺度。历史最大误差不是未来误差的认证上界；此项仅是法线方向的必要条件，不是完整三维鲁棒性或物理夹持证明。已有 `calibration_centering_margin_override` 只控制原横向夹爪居中检查，语义保持。

本次计划的连续允许法线区间为约 [-0.500, +4.363] mm，最终 FK 姿态为 [-0.759, +3.821] mm，均不能覆盖 ±4.606 mm 的现有经验误差尺度。新检查在任务运动入口和每次绑定动作提交前执行，近场换计划会重新计算；闭爪前还用新鲜 accepted 编码器 FK、实际开度重检。该计划会在预抓取前拒绝，无需再花数分钟移动后空夹。

这修复的是已知误差预算不足却仍许可接触的缺口，并未声称绝对定位已校准。小目标继续自动抓取前，需要在实际工作姿态下获得独立相机/工具配准证据或足够可靠的近场闭环定位；降低误差参数以让门禁通过不构成标定。

### 当前流入口的源码修复

`charuco_tracker.py` 增加显式 `realsense_runtime` 分支，当前流 launch 默认选择此分支并加载项目隔离的 SDK 环境。此分支拒绝同时传入静态 YAML；原 USB/V4L2 入口继续走原分支。当前流用 `runtime_profile.color_intrinsics`，检查实际尺寸、frame、图像 topic、SDK/device 来源和明确关闭的 RGB 重映射状态。实际导入 SDK 版本必须与相机 producer 一致；缺失、失败或不匹配不回退旧参数。

角点经 SDK 反投影归一化，再以 `K=I,D=None` 做 PnP 和 LM。最终 RMS、坐标轴和原点均按同一 SDK 投影回原图像素；所有角点须在相机前方，非有限值或投影失败拒绝。原 optical→camera_link 转换和验证器 1.5 px 质量阈值保持。新增 quality 信息包含相机模型摘要/哈希、实际 SDK 版本和模块来源、精确 `source_stamp_ns`，以及方格、标记边长和字典；launch 暴露字典参数供显式选板。

第一次有效模型固定后，模型变化会锁存拒绝，需重新启动该 tracker 才能建立新会话；本轮没有执行此启动。每帧检测前与发布 TF 前均有界重读参数，单后台线程使用私有 XMLRPC；过期响应不复用，回调和读取均采用非阻塞互斥。独立审阅发现的并发结果抢占、关闭后消费结果问题已用确定性调度复现并修复。最终发布还检查停止状态。相机参数读取时间仍不是曝光元数据，不能据此伪造历史帧的相机模型。

此补丁修复当前流标定计算入口，不包括采集新姿态、求得新外参、部署外参或实机验收。现有 `capture_exact.py` 和最新 TF 窗口验证器的完整归档限制见上节。
