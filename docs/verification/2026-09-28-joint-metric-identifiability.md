# 2026-09-28 固定内参与尺度的 metric 手眼 / 关节零位诊断

只读离线结果：完整 10 参数模型在保留的 22 张训练图像上局部可辨识，能解释校准区域较大部分姿态间漂移；任务区域的留出结果仍不一致，不能作为可部署的标定修复。没有改写 K、手眼、URDF、零位、控制或抓取参数。

输入为 `grasp_repair_resume_20260928T120606Z/camera_intrinsics_sensitivity/{detected_rays,report}.json`。使用每帧不变的 SDK 光线 PnP `baseline_T_camera_board`，没有使用报告中的 candidate K / candidate pose。55 张捕获逐一核对原 capture SHA、图像时间戳、控制 epoch，并从对应 accepted_joint_positions 重建 FK。重建与归档 A 的最大差为 4.48e-13 mm / 5.43e-14°。

保留 22 training 用于估计，8 independent_validation 和 25 task_pose_validation 只评估。每个 dataset / epoch 采用独立固定板位姿 Y；位置均值与旋转弦平均消去 Y。两个只有一帧的 task epoch 没有组内一致性验证信息，不能把其零残差记为通过。

模型仅含 X 的 3 平移和 3 旋转小修正、q2/q3/q4/q5 固定零位。q1/q6 固定以去除端部 gauge，机器人长度、棋盘尺度及相机内参固定。单位为 X 平移 mm、旋转与零位 degree；主残差单位 1 mm / 0.1°。预先声明界为 X 每轴 ±10 mm / ±3°，零位每轴 ±10°；从零单次起始，不依据验证集调参或挑选权重。

## 可辨识性

主权重中心差分 Jacobian 满秩 10，条件数 41.912。差分步长 0.001 / 0.003 参数单位结果一致。相对秩阈值 1e-7 并设绝对缩放噪声底 1e-6，防止重复姿态的浮点残差被误算成满秩。旋转残差单位改为 0.25° / 1° 仍满秩，条件数为 31.244 / 47.841。

最弱方向主要混合 q2、q3 对向零位与 X_z。训练 q2 / q3 范围仅 4.043° / 3.516°，因此满秩不能解释为这些零位已经准确测定；误差模型以外的相机、关节姿态依赖误差仍可能被固定零位吸收。参数敏感性数值是所设单位下的线性代数结果，不是实测置信区间。
