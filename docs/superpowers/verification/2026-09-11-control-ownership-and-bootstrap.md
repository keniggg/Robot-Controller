# 2026-09-11 控制权切换与自动运动确认恢复

操作者要求：勾选上位机关节直控时，滑条拥有最高优先级，机械臂不得自主
移动；取消勾选后才允许自主运动，滑条实时显示各关节实测角度。本次沿用
不自动发送扭矩失能命令的约束。

## 控制权

GUI通过锁存主题和同名持久参数`/gui/joint_direct_mode`发布选择，各关节
控制面板同步此选择，重启GUI继承参数。勾选后驱动只接受gui_direct和
gui_direct_sync来源，保护不再随0.25秒手势窗口结束。切换时串行清除旧
目标插值、端点补偿归属和未完成的运动确认，保留实测位置保持与已存在
的有效确认。取消勾选后拒绝旧滑条消息，控制器必须先同步到3mrad以内。

任务启动和每次绑定动作均检查直控模式；gateway拒绝自动位姿、关节、
夹爪、jog及确认恢复入口。勾选时取消当前MoveIt轨迹，驱动同时阻止非
滑条命令。此取消不停止控制器、不发送torque_off。GUI复选框自身不再
调用暂停/启动控制器服务。

自动模式的滑条变为只读，每次joint_states按关节名称更新数值，阻断Qt
valueChanged信号，避免显示刷新变成关节指令。手动模式保留操作目标，
实时反馈不会把正在调整的滑条拉回去。

## 自动确认恢复

原start_cb只接受CONFIRMED，而恢复只接在GUI滑条上，造成已对准后仍
等待手动运动的闭环。新增auto_confirm_actuation_from_observation，仅
对新鲜PENDING:POSITIVE_ENABLE_REQUESTED或COMMAND_SYNCHRONIZED生效。
DISABLED、过热、响应超时、缺失/过期状态继续拒绝。手动模式永不恢复。

start_cb先验证并冻结本轮FAR_FIELD_OBSERVATION_PLAN，再经原绑定动作
互斥入口调用新gateway服务。gateway同步实测位置、严格规划观察位姿，
仅取原碰撞检查轨迹开头每关节最多0.025rad的片段；裁切点位于原关节
路径边上，拒绝反向片段、非有限数据、过短轨迹及起点偏差超过0.003rad。
重新定时必须保持同一条位置路径，按原硬件速度限制执行；消费整个缓存，
不保留未执行的后半段。完成后必须读到真实CONFIRMED，任务才继续原
观察/近场/接触流程。无响应不重试、不放宽确认，不执行完整接触路径。

驱动原来只比较每次下发目标与最近反馈，在缓慢且跟随良好的轨迹上永远
达不到0.02rad命令变化门槛。现对短时间连续命令累计位移，仍要求真实
同方向编码器响应；间断、过长窗口、先于指令的反馈运动、归属改变和
反馈跳变都会丢弃该基线。没有由静止反馈或成功写torque_on伪造确认。

连续响应确认也分别累计命令和编码器的位移，消除固定偏差的影响，仍
